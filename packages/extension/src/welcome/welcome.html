holt is installed

Screenshots, tab recordings and voice or typed notes for QA, written as markdown straight into your project's repo.

1. Start the holt server

holt sends every capture to a small server on your own machine, which writes it into your project. Nothing works until one is running. In your project, either run the standalone server (it listens on http://127.0.0.1:4848):

npx @velvet-thunder/holt

or add the Vite plugin to vite.config.ts (holt then finds the server on your app's pages by itself):

import holt from "@velvet-thunder/holt/vite";

export default defineConfig({ plugins: [holt()] });

2. Capture

Pin holt to the toolbar (puzzle-piece menu → pin). Clicking its icon opens holt's menu, whose Settings item opens the settings panel. The shortcuts work without the menu:

Change them, or give the unset ones a key, at chrome://extensions/shortcuts.
